# じゃんけんアプリ

Pythonで作成した、GUIで遊べるじゃんけんアプリです。

## 概要
「グー」「チョキ」「パー」のボタンを押すと、コンピュータがランダムに手を選び、勝敗を判定して表示します。
手は画像で表示され、直感的に遊べるようにしています。

## 使用技術
- Python 3
- tkinter（GUI作成）
- Pillow（画像の読み込み・表示）

## 実行方法
1. Pillowをインストールします
   pip install pillow
2. このフォルダに移動し、以下を実行します
   python janken_gui.py
